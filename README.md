# Bookshelf — Darkhax Library

[![Download Latest](https://img.shields.io/github/v/release/FinancialWar37/bookshelf-api-lib-mod?style=flat-square&label=Download&color=brightgreen)](https://github.com/FinancialWar37/bookshelf-api-lib-mod/releases/latest)
[![Forge](https://img.shields.io/badge/Loader-Forge-orange?style=flat-square)](https://files.minecraftforge.net/)

A shared library for Darkhax mods providing utilities for potions, enchantments, and loot tables.

![Bookshelf — Darkhax Library Preview](https://cdn.modrinth.com/data/VUkUwfUG/3fc6fd38e0b735af4b577f5c041367bbce6df1b9.png)

## Features

- Enchantment condition utilities and API hooks
- Loot table modifier system for mod pack creators
- Potion and effect utility helpers
- Used by Enchantment Descriptions, Game Stages
- Over 10 years of active Minecraft modding support

## Installation

1. Install [Minecraft Forge](https://files.minecraftforge.net/) for your Minecraft version
2. Download the JAR matching your exact Minecraft version above
3. Place the JAR into your `.minecraft/mods/` folder
4. Launch Minecraft with the Forge profile

## Requirements

- **Mod Loader:** Forge
- **Minecraft:** See download table above
